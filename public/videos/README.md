# 데모 영상

**이 폴더의 영상은 전부 자리표시자입니다.** 실제 데모 영상이 아니며,
화면 구성과 재생 동작을 확인하기 위해 `scripts/generate-placeholder-media.js`
로 생성한 합성 장면입니다. 대외 자료로 사용하면 안 됩니다.

## 교체 방법

같은 이름으로 덮어쓰면 됩니다. `data/technologies.json` 의 `media` 경로는
그대로 두어도 동작합니다.

| 파일 | 용도 | 권장 사양 |
|---|---|---|
| `<id>.mp4` | 상세 화면 재생, 데모 실패 시 폴백 | 1280×720, H.264, 무음 |
| `<id>.loop.mp4` | 카드 썸네일 루프 (자동재생) | 640×400, H.264, 무음, 6초 내외 |
| `<id>.webm` / `<id>.loop.webm` | 대체 소스 (선택) | 같은 화면의 VP9 판본 |
| `../thumbnails/<id>.jpg` | 포스터 이미지 | 영상의 대표 프레임 |

`.webm` 이 없으면 mp4 만 쓰므로 실사용 브라우저에서는 문제가 없습니다.
코덱이 빠진 Chromium 빌드(CI·헤드리스 환경)까지 지원하려면 함께 두세요.

## 루프 영상 주의사항

카드 루프는 자동재생되므로 다음을 지켜 주세요.

- **무음**으로 인코딩합니다 (오디오 트랙이 있으면 자동재생이 차단됩니다)
- 화면 상단·하단에 **자막이나 HUD 텍스트를 넣지 마세요**. 카드가 그 위에
  대분류·검증 배지·대표 수치를 얹기 때문에 겹쳐 읽힙니다
- 피사체를 크게 잡으세요. 카드 크기에서는 전체 화면 구도가 읽히지 않습니다
