## infiniq-wordmark.png

INFINIQ 워드마크 (흰색, 배경 투명). 1436×276.

**출처**: 「2026 국제치안산업대전 전시 기획안 Ver.2」 표지의 회사 로고를
16배로 렌더해 잘라낸 것입니다. 원본 벡터가 아니라 래스터입니다.

**교체 권장**: 홍보팀에서 원본 SVG 를 받으면 `infiniq-wordmark.svg` 로 넣고
`src/app/(public)/layout.tsx` 의 확장자만 바꾸면 됩니다. 지금 파일은 헤더
크기(높이 24~28px)에서는 문제없지만 크게 쓰면 가장자리가 뭉갭니다.

**색**: 흰색 단색이라 어두운 배경 전용입니다. 밝은 배경에 쓰려면
`filter: brightness(0)` 로 검게 뒤집거나 원본 SVG 를 받으세요.
